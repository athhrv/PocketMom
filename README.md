# 🌤️ PocketMom

PocketMom is an AI-inspired weather companion that doesn't just tell you the weather—it talks like a caring Indian mom.

Instead of boring weather updates, PocketMom gives weather-based reminders with a mix of care, sarcasm, and motivation.

## ✨ Features

- 🌦 Real-time weather using OpenWeather API
- 🎙 PocketMom voice responses
- 💜 Caring & sarcastic mom-style messages
- 🔍 Search weather by city
- 🌡 Temperature, humidity, wind speed & feels like
- ☁ Dynamic weather icons
- 🎨 Modern responsive UI

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenWeather API



## 🚀 Getting Started

```bash
git clone https://github.com/athhrv/PocketMom.git
cd PocketMom
```

### Install backend

```bash
cd server
npm install
npm run dev
```
